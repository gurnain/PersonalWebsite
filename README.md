# Gurnain Saini, personal website

Source for https://gurnain.squre.org. A single About page built with Next.js.

- All text, links and lists live in `src/content.ts`.
- The page is `src/app/about/page.tsx`, styled by `about.module.css` next to it.
- Colours for light and dark themes are in `src/app/globals.css`.

```bash
npm install
npm run dev
```

Pushing to `main` deploys to Vercel.
